# Product

<!-- impeccable:product-schema 1 -->

## Platform

ios

## Users

The owner plays on an iPhone 15 Pro Max and wants direct access to the game.

## Product Purpose

Open straight into Burnout 3: Takedown. On first use, the player supplies their
own ISO through Files. Keep a local copy so subsequent launches start automatically.

## Capabilities and Constraints

UIKit / Objective-C++, landscape, local game data, one game session per process.
The host supports the NTSC-U SLUS-21050 disc image only. Preserve touch controls,
audio, GPU rendering and saved profiles. Import stays on device; no network upload.
The ISO is supplied separately and is not packaged in the app.

## Brand Commitments

The owner's 2026-10-17 request removes the launcher and its library, metadata,
cover and launch button. The only setup action is “Upload ISO file”.

## Evidence on Hand

Burnout 3 native host, existing local disc support and on-device launch reports.
