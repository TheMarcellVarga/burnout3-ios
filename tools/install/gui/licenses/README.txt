Licences shipped with Takedawn. The setup window's "About and licences" shows them.

  takedawn-LICENSE.txt        Takedawn (MIT)
  xboxrecomp-LICENSE.txt      the recompiler toolkit (MIT, sp00nz)
  xboxrecomp-NOTICE.txt       third-party parts of the toolkit and their licences
  xboxrecomp-LGPL-2.1.txt     the LGPL 2.1 text those parts refer to
  Qt-NOTICE.txt               how Qt is used (dynamically linked) and where its source is
  Qt-LGPL-3.0.txt, Qt-GPL-3.0.txt   Qt's licence
  Qt-THIRD-PARTY.txt          notices and licences of the other projects' code inside Qt

The first four are copied from the repositories when the program is packaged
(packaging/make-macos-bundle.sh).
